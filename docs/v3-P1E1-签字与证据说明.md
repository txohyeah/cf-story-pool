# P1-E1 签字与证据说明

## 接口与校验

- `POST /api/runs/:id/items/:itemId/diff-sign`：body `{project_id,decision,reason?}`；itemId 为执行记录 ID；仅开放轮次中的 DIFF 可签，decision 为 accept/reject，reason 最多 500 字符；返回 `{ok,decision,signed_at}`。改签覆盖原值并记录 prev；执行结果仍为 diff。既有执行重跑会清除签字。
- `POST /api/runs/:id/items/:itemId/evidence`：body `{project_id,kind,locator,sha256,byte_size?,summary?,artifact_key?}`；返回 `{ok,id,artifact_key}`。仅存引用，不上传文件。
- `DELETE /api/runs/:id/items/:itemId/evidence/:refId?project_id=N`：核验项目、轮次、执行与引用归属，开放轮次可删除；返回 `{ok:true}`。
- `POST /api/runs/:id/close`：body `{project_id,confirm_partial?,confirm_unsigned_diff?}`。先检查未执行，再检查未签 DIFF；分别需要显式确认，成功返回 `{ok,stat}`。未签 DIFF 的确认次数写入关轮事件。
- `GET /api/runs/:id?project_id=N`：items 增加 execution_id 和 evidence 数组，保留 diff_reason/diff_decision/diff_signed_at。所有写操作记录 regression_events；原执行写入和 legacy 分支未改。

| 输入或状态 | 约束 / 失败行为 |
|---|---|
| 项目、轮次、执行、证据归属 | 不匹配 404；已关轮写操作 409 |
| decision / reason | accept 或 reject；reason 字符串至多 500 |
| kind / locator | image、log、assertions、package；locator 非空字符串至多 500 |
| sha256 | 必填 64 位小写十六进制；大写、63 位、64 位非 hex 均 400 |
| byte_size / summary | 非负安全整数或 null；字符串至多 200 |
| artifact_key | 可选非空字符串至多 100；同执行重复返回 409 |
| 证据数量 | 每执行最多 10 条，数据库插入守卫并发校验，超限 409 |

摘要校验实际代码：`typeof body.sha256!=='string' || !/^[0-9a-f]{64}$/.test(body.sha256)`（worker_src/_worker.js:1838）。自动 key 代码 `body.kind+'-'+(count+1+attempt)`（:1846），同 kind 连续新增得到 log-1、log-2、log-3；自动编号冲突依次重试最多 20 次，显式重复 key 返回 409。

## 关轮并发守卫

实际 UPDATE（参数按代码绑定）：
```sql
UPDATE test_runs SET state='closed',closed_by=?,closed_at=?,updated_at=?
 WHERE id=? AND project_id=? AND state IN ('planned','running') AND
 (SELECT COUNT(*) FROM regression_baseline_items i LEFT JOIN tc_executions e ON e.run_id=? AND e.baseline_item_id=i.id
  WHERE i.project_id=? AND i.baseline_id=? AND COALESCE(e.result,'')='')=? AND
 (SELECT COUNT(*) FROM regression_baseline_items i JOIN tc_executions e
  ON e.run_id=? AND e.baseline_item_id=i.id AND e.project_id=i.project_id
  WHERE i.project_id=? AND i.baseline_id=? AND e.result='diff' AND e.diff_decision IS NULL)=?
```
两个计数与检查时一致才更新；结果变化时重新检查并返回 409，避免静默越过确认。
