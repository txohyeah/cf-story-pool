# P1-G1 报告前端说明

轮次页在详情行提供 DIFF 签字与证据面板，已关闭轮次仅可查看证据；关轮按服务端响应依次确认未执行、未签 DIFF，并保留前次确认标志。关轮后可生成报告，已有未冻结报告时先询问是否查看。

报告页按项目和版本显示摘要；详情从 `snapshot_json` 解析冻结快照，展示计数、条目、比较和哈希，支持浏览器下载 JSON。版本筛选用现有 `/api/releases?project=` 返回的 version 对报告 release_version 做客户端匹配。

| 交互 | 方法与端点；请求字段 |
|---|---|
| 签字 | POST `/api/runs/:run/items/:execution/diff-sign`；project_id、decision、reason |
| 添加证据 | POST `/api/runs/:run/items/:execution/evidence`；project_id、kind、locator、sha256、可选 byte_size、summary、artifact_key |
| 删除证据 | DELETE `/api/runs/:run/items/:execution/evidence/:ref?project_id=` |
| 关轮 | POST `/api/runs/:run/close`；project_id、可选 confirm_partial、confirm_unsigned_diff |
| 报告前置检查与候选轮次 | GET `/api/reports?project_id=&run_id=`、GET `/api/runs?project_id=`；只列其他已关闭轮次 |
| 创建报告 | POST `/api/reports`；project_id、run_id、可选 comparison_run_id、template_version |
| 报告列表/详情 | GET `/api/reports?project_id=`、GET `/api/reports/:id?project_id=` |
| 批准/冻结/更正 | POST `/api/reports/:id/approve|freeze|revision`；project_id |
| JSON 下载 | GET `/api/reports/:id/export?project_id=&format=json`，浏览器直接下载 |
| 页面基础数据 | GET `/api/me`、`/api/bootstrap`、`/api/releases?project=`、`/api/runs/:id?project_id=` |

状态：报告 draft 显示批准，approved 显示冻结，frozen 显示更正（创建新 revision），任意状态均可导出。任务书“冻结后无批准/更正按钮”与“frozen 显示更正”冲突；本实现保留后者的更正入口，新建草稿，原冻结报告不变。

错误在页面或表单 `.err` 中显示后端原文，包括轮次关闭、非 DIFF、sha256 不合法、证据上限、重复 key、报告已存在、轮次不可比及其 reasons；网络错误在本页提示，401 跳登录。证据仅引用，不上传文件。

验证：两页内联脚本通过 `node --check /tmp/p1g1-runs-0.js`、`node --check /tmp/p1g1-reports-0.js`；合成 DOM 检查签字按钮、未执行证据禁用、恶意文本转义、连续两次关轮确认的标志累积、冻结报告无批准入口且可新建更正。未使用线上数据或部署。runs.html 173 行，reports.html 52 行。

代码定位：签字和证据守卫 `dist/runs.html:135`，关轮标志累积 `:148`，签字/证据 API `:160`，报告创建 `:165`；报告动作与转义 `dist/reports.html:25`、`:44`。7 个页面各含一行报告导航；除 runs 外其余五个既有页面仅新增导航行。
